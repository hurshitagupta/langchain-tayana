
Question: What is LangChain?
Answer: LangChain is an open‑source framework that enables developers to build applications powered by large language models by chaining together prompts, models, and external tools or data sources.

Question: What is a Runnable in LangChain?
Answer: A Runnable in LangChain is a modular, composable abstraction that represents any callable component—such as a prompt, model, chain, or tool—allowing you to chain, parallelize, or transform its inputs and outputs using a unified, functional‑style interface.

Question: What is an output parser?
Answer: An output parser is a component that interprets and converts a model’s raw generated text into a structured format (e.g., JSON, objects, or specific data types) for downstream use.
