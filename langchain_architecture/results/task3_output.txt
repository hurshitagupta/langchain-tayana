{'answer': '**LangChain** is a Python (and increasingly multi‑language) framework that makes it easier to build **applications powered by large language models (LLMs)**.  \n\n- **Purpose:** It abstracts away the boiler‑plate needed to connect LLMs with other pieces of a typical AI‑driven product—such as prompt templates, external data sources, tool‑calling, and workflow orchestration—so developers can focus on the high‑level logic of their app.  \n- **Key concepts:**  \n  * **Models** – wrappers around LLM APIs (OpenAI, Anthropic, Llama, etc.).  \n  * **Prompts** – reusable, templated prompt objects that can be rendered with variables.  \n  * **Chains** – ordered sequences of calls (e.g., prompt → LLM → post‑processing) that define a workflow.  \n  * **Retrievers** – components that fetch relevant documents or pieces of information (from a vector store, database, search engine, etc.) to ground the model’s response.  \n  * **Tools** – external functions or APIs (e.g., calculator, web search, code execution) that the LLM can invoke during a conversation.  \n\n- **Design principle:** LangChain follows **dependency inversion**, meaning the high‑level application logic depends on abstract interfaces (e.g., an abstract `Retriever` or `LLM`) rather than concrete implementations. This lets you swap out the underlying model, vector store, or tool without rewriting the rest of the code.\n\nIn short, LangChain is a modular, extensible toolbox that lets you wire together LLMs, data retrieval, prompting, and external tools into robust, production‑ready AI applications.', 'sources': 2}
